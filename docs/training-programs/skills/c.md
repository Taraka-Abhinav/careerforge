# C Skill Training Program

## Program Goal
Build practical C proficiency through an 8-week project-oriented training path.

## Learning Outcomes
- Understand fundamental C concepts.
- Apply C in realistic implementation tasks.
- Debug and optimize common workflows.
- Produce one portfolio-ready skill project.

## 8-Week Curriculum
- Week 1: Setup and fundamentals.
- Week 2: Core concepts and syntax.
- Week 3: Applied mini-project.
- Week 4: Intermediate patterns.
- Week 5: Testing, debugging, and quality.
- Week 6: Integration with adjacent tools.
- Week 7: Assessment project.
- Week 8: Portfolio polish and interview prep.

## Practice Structure
- Daily: 60-90 minutes guided practice.
- Weekly: one challenge assignment.
- End of program: one documented showcase project.

## Assessment
- Weekly quiz.
- Practical coding or design task.
- Final skill demonstration with rubric review.

## Completion Criteria
- All weekly tasks submitted.
- Final project delivered with documentation.
- Minimum score of 80/100 on final rubric.
