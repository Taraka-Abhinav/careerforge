# CareerForge Training Program System

This document defines a repeatable method to build high-quality training programs for every career and skill listed in the SEO plan.

## Program Design Principles
- Outcome-first: every module maps to a job-ready skill.
- Project-led: every 2-3 modules produce portfolio evidence.
- Assessment-backed: weekly quizzes, code reviews, and rubric scoring.
- Industry-aligned: tools and workflows mirror real teams.
- Placement-focused: resumes, mock interviews, and capstone defense.

## Standard 16-Week Career Program
- Weeks 1-2: Foundations and setup
- Weeks 3-6: Core technical depth
- Weeks 7-10: Intermediate build and integrations
- Weeks 11-13: Advanced concepts and performance/security
- Weeks 14-15: Capstone project and documentation
- Week 16: Interview prep and hiring assets

## Standard 8-Week Skill Program
- Week 1: Fundamentals and setup
- Week 2: Core syntax or concepts
- Week 3: Applied mini-project
- Week 4: Intermediate patterns
- Week 5: Debugging and optimization
- Week 6: Real-world integration
- Week 7: Assessment project
- Week 8: Portfolio polish and interview Q&A

## Mandatory Deliverables for Every Program
- Learning objectives (5-8 measurable outcomes)
- Weekly plan with practice tasks
- 3 projects (beginner, intermediate, advanced)
- Assessment rubric (correctness, code quality, communication)
- Toolchain and references list
- Capstone evaluation checklist

## Quality Rubric (Pass >= 80)
- 30 points: Technical correctness
- 20 points: Architecture and design choices
- 20 points: Testing and reliability
- 15 points: Documentation clarity
- 15 points: Communication and presentation
