1 Objective: Programmatic Content Integration
To launch our high-authority SEO growth machine, we are moving away from static hard-coded
pages. Instead, we are building a structured content database.
Your Task: Create a highly structured TypeScript file ( .ts) for each target path. These files
will be dynamically loaded by our programmatic page generation framework in Next.js (/career/[id]
and /skill/[id]).
Content Standard Rule
Every single file must strictly provide realistic, deep, and highly valuable career and skill
guidance. No Lorem Ipsum, no thin explanations, and no placeholder content. The quality
must immediately convince cold visitors to sign up.

2 The TypeScript Schema ( src/types/seo.ts)
All created data structures must strictly implement this TypeScript interface to compile correctly
with our dynamic page layouts:
TypeScript Contract Definition
export interface SEORoadmapPage {
slug: string; // URL-friendly identifier
title: string; // Primary Page H1 heading
metaDescription: string; // Optimized SEO description (150-160 chars)
introduction: {
whatIsIt: string; // Direct definition
whyItMatters: string; // Professional demand background
futureScope: string; // Horizon outlook
};
roadmapSteps: {
phase: 'Beginner' | 'Intermediate' | 'Advanced' |
'Projects' | 'Industry Readiness';
title: string;
description: string;
recommendedOrder: number;
}[];
requiredSkills: {
name: string;
description: string;
priority: 'high' | 'medium' | 'low';
}[];
recommendedLearningOrder: string[]; // Sequential order of topics
projectIdeas: {
title: string;
difficulty: 'Beginner' | 'Intermediate' | 'Advanced';
description: string;
architectureHint: string; // Tooling, database, or API design
}[];
industryTools: string[]; // Specific tech stack tools
salaryInfo: {
indiaRange: { fresher: string; experienced: string };
globalRange: { fresher: string; experienced: string };
};
careerOpportunities: string[]; // Job roles (e.g. "ML Engineer")
faqs: { question: string; answer: string }[]; // Rich-Snippet ready
commonMistakes: string[]; // Pitfalls beginners make
tipsForSuccess: string[]; // Actionable habits for fast learning
curatedResources: { title: string; url: string; type: string }[];
}
